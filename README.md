# PL Labs website

Studio site for **PL Labs**: an About page plus a page for every game
(Soul Rush, Soul Block, ...). Served by Netlify from the root of `main`.
Plain HTML/CSS/JS, no build step.

See **CLAUDE.md** for the layout, how to add a game, and the files that must
never move (`app-ads.txt`, `privacy.html`).

Soul Rush screenshots are generated by `scripts/capture-screenshots.mjs` in the
(private) game repo, which writes into `games/soul-rush/assets/screenshots/`.
