# Soul Rush — marketing site

Static marketing site for **Soul Rush** (PL Labs), a one-tap gothic survival
runner. Served by GitHub Pages from the root of `main` — plain HTML/CSS/JS,
no build step.

- `index.html` — landing page
- `privacy.html` — privacy policy (linked from the Google Play listing)
- `assets/screenshots/` — real gameplay captures, generated by
  `scripts/capture-screenshots.mjs` in the (private) game repo and copied here

To update screenshots: run the capture script in the game repo, which writes
into this repo's `assets/screenshots/`, then commit and push here.
